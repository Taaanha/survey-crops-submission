# Handoff: W4 soil pH and organic carbon (13 Nov 2026, branch w4-soil-ph-oc)

## Source check
- Dataset: ISRIC SoilGrids 2.0, 250 m. Licence **CC BY 4.0**. Docs: https://docs.isric.org/globaldata/soilgrids/index.html
- Free and open: the REST API worked with no key or login (13 Nov). Fair use: 5 calls per minute (we space calls 13 s). ISRIC calls the REST API beta and says it may be paused with no notice; fall back to the saved CSV.
- Cite: Poggio et al. 2021, SOIL 7, 217-240, https://doi.org/10.5194/soil-7-217-2021

## What was built
- `src/acquire/soilgrids_ph_oc.py` + `scripts/fetch_soil_ph_oc.py`: pH (phh2o) and organic carbon (soc), layers 0-5, 5-15, 15-30 cm, statistics mean, Q0.05, Q0.5, Q0.95. Conversion = raw / `d_factor` from the response (pH x10 -> pH; dg/kg -> g/kg). A different `mapped_units` string is refused. Tests include d_factor 100 and a real-file check (raw / d_factor reproduces every value; pH 3-10).
- `data/processed/soilgrids_ph_oc_points.csv` (168 rows, small): dataset, source_url, layer, depth, statistic, units, resolution 250 m, fetch_date, status, reason.
- `src/compute/soil_chem/` loader (measured numbers with provenance) + MODULE.md.
- `docs/w1b_data_status.csv`: rows `soilgrids_ph`, `soilgrids_soc` (partial). `sat_layers.intake.build_status` now keeps them on rebuild.
- W4 `organic_matter` indicator carries `soil_baseline`; the card says "SoilGrids model estimate, 250 m, not a soil test; confirm with a local soil test". Not in the priority matrix. A soil gap is named under Information gaps.

## Result: mostly gaps
Only **Brahmanbaria** has values (SOC 24.3 / 21.0 / 17.7 g/kg, pH 5.4 / 5.3 / 5.3 at 0-5 / 5-15 / 15-30 cm). Cumilla, Feni, Noakhali, Sylhet and both demo-field tile centres return null: masked cells (repeated query gave the same null; cells 1-2 km away have values). Marked gaps; not interpolated, not moved. Decision for Tanha: give a cropland point per district to fetch.

## Not done / caveats
- The `uncertainty` field was not fetched (definition not verified).
- SOC is carbon, not organic matter; no conversion factor (none sourced).
- Layers are shown one by one; quantiles are not combined across depths.
- Not wired to `app.py` (shared-file rule).
