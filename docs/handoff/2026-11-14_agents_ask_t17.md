# Handoff: T17 ask agent (2026-11-14)
Built: `src/agents/ask_agent.py` (loop, max 6 steps, HF client on `requests`, keyword router fallback), `ask_tools.py` (5 tools over the cited API), real `POST /api/v1/ask` in `app.py` (in-process calls, `httpx` added to requirements-api.txt for that), Ask page `web/pages/ask.js` (`#/ask`, mic bn-BD/en-US, speaker hides without a voice), tests in `test_ask_agent.py` and `src/api/test_app.py`.
How answers stay correct: the model only picks tools. The text is the endpoints' own guarded sentences (or sentences built from their numbers); the model's one extra sentence is dropped if it has a number not in the data, "predict/forecast", or a crop the data does not name. No tool result, no answer.
To switch the model on: set `HF_TOKEN` (and optionally `HF_MODEL`) as a Render environment variable. Until then `/ask` answers from the keyword router and says so (`RULE_ROUTER` notice, `data.llm_used: false`).
