## 2. What "official boundary" means, and why it matters

At the moment each district's numbers come from a **20 km square around one point** in the district, not from the district's real shape.

An **official boundary** is a map file that draws each district's true outline. With it we can:

- average NASA data over the **whole district**;
- draw all 64 districts on the map.

The likely free source is **geoBoundaries ADM2 for Bangladesh** (open licence; the exact licence must be verified in W1). OCHA's file on HDX is the backup.

### W1. 64 districts + every challenge dataset + a common grid (Data Fusion core)

**Boundaries:**
- geoBoundaries ADM2 Bangladesh, licence checked and recorded.
- Save a simplified GeoJSON (< 2 MB) to `data/reference/`.

**Common analysis grid: 0.1° (the IMERG grid) over Bangladesh.**
- Every dataset is resampled to it, and the rule is written down in `docs/harmonisation.md`:

  | Dataset | Native size | How it goes onto the 0.1° grid |
  |---|---|---|
  | POWER | about 0.5° | nearest cell |
  | SMAP | 9 km | mean |
  | MODIS | 250 m | mean |
  | NASADEM | 30 m | mean + slope |
  | GRACE-FO | 0.5° mascon | nearest; flagged as regional |

- Then each layer is averaged over each district polygon.
- The output is one **district × season feature table** for all 64 districts, 2001–2024, with the coverage years per column.

**Datasets** (all free; each download is verified first, and the source URL is recorded):

| Dataset | Gives | Coverage | How |
|---|---|---|---|
| NASA POWER | Tmax, Tmin, RH, wind, solar, ET0 inputs | 1981– (use 2001–2024) | POWER API, district centroid |
| GPM IMERG V07 daily | Rain, heavy-rain days, dry spells | 2000– | GES DISC subset or Giovanni area averages. **Pick the fastest free route first** |
| SMAP L4 | Root-zone soil moisture and anomalies | 2015– | AppEEARS (Earthdata login) |
| MODIS MOD13Q1 | NDVI / EVI, 250 m, 16-day | 2000– | ORNL DAAC web service or AppEEARS |
| Landsat via HLS | 30 m NDVI for demo fields | 2013– | AppEEARS (HLSL30 / HLSS30) |
| ECOSTRESS | Land-surface temperature + ET at 70 m for demo fields (actual evaporation, heat stress) | 2018–, irregular passes | AppEEARS |
| GRACE / GRACE-FO JPL mascons | Long-term water-storage trend (groundwater context) | 2002– | PO.DAAC. Labelled "regional, about 300 km effective" |
| NASADEM | Elevation, slope, low-lying zones | 30 m | AppEEARS |
| GEDI L4B | Biomass | 1 km | Shown as context only, with the honest note "mostly measures trees, not field crops" |
| OPERA DSWx (existing T3) | 30 m flood history | Feni + Cumilla demo | Already built |
| SoilGrids (existing) | Texture, organic carbon | 250 m | Already in use |

**Two tiers, labelled in the app:**
- **Standard:** all 64 districts.
- **Field detail:** demo fields with HLS, ECOSTRESS, OPERA and NASADEM at 30–70 m.

**Acceptance:**
- The feature table has 64 rows per season.
- Every column has dataset, units and source URL.
- A test checks that the district averages from a fixture grid match a hand calculation.
- Raw files stay in `data/raw/` or a Hugging Face Dataset. Only small CSV/parquet files go in git.

### W2. Understanding Conditions (Layer 1 indicators)

For each district, season and crop stage, compute:
- **Heat-stress days:** crop-stage limits (existing).
- **Frost / cold-risk nights:** Tmin below cited limits (cold waves in the north).
- **Extreme-rain days:** IMERG, cited threshold.
- **Dry spells:** longest run of rain-free days.
- **Evaporation:** FAO-56 ET0 and crop ET, compared with ECOSTRESS ET on the demo fields.
- **Soil-moisture anomaly:** SMAP z-score against the same dates in other years.
- **Vegetation-stress anomaly:** MODIS NDVI z-score.
- **Water-balance deficit:** existing FAO-56 water balance.
- **Long-term trends:** with the POWER vs IMERG homogeneity check (T9b), so a broken record isn't presented as a trend. GRACE-FO storage trend per district.

**Satellite vs ground check:** compare POWER and IMERG against published BMD station normals for a few stations (R sources them). Report the bias honestly.

**Acceptance:**
- Hand-counted fixtures for every indicator.
- Each indicator has a plain-English one-liner for the explainer.

### W3. SI and modelling: three problems, two methods each, honest comparison (Layer 2)

| Problem | Method A (simple) | Method B (SI) | How we score it |
|---|---|---|---|
| **Seasonal transitions and bare-field periods** from MODIS NDVI | Fixed NDVI threshold (cited) | Smoothed curve (Savitzky–Golay) + change-point detection | Error in days against official BRRI/BARI sowing and harvest windows, per district |
| **Stressed seasons**: when do current crops show unusual stress | z-score rule on the fused features | Isolation Forest on the fused feature table | Does it flag known bad seasons (Aug 2024 flood, documented cold waves, 2017 haor flood)? Hits and false alarms |
| **Season types**: which past seasons resemble each other | Percentile rule (top 20% heat or rain) | k-means clustering (k chosen by silhouette) | Leave-one-year-out: which separates the existing rotation's problem years better |

- **Uncertainty:** bootstrap intervals on every 24-season statistic, plus a model card per model in `src/ml/` (n, metric, limits, "needs local validation").
- If Method B doesn't beat Method A, the app uses A and says so.

**Acceptance:** metrics JSON for both methods, model cards, and fixed random seeds.

### W4. Rotation Strategy Exploration (Layer 1 + API)

**Input:**
- the **current rotation** (required), which is the baseline;
- priorities: water, soil health, low risk, income;
- water available;
- equipment, e.g. "no power tiller" (only applied to crops with a cited equipment need);
- market preference.

**Output:** the baseline plus at least 2 alternatives, each with these indicators:

| Indicator | Source |
|---|---|
| Water use (**Kc-weighted FAO-56**, never cut) | Existing |
| Problem years out of 24, with bootstrap range | Existing + W3 |
| Bare-field days per year | W3 phenology + calendar |
| **Erosion exposure** = bare days × heavy-rain days × slope class | IMERG + NASADEM |
| **Nutrient cycling**: legume nitrogen fixing yes/no | Cited |
| Organic matter / residue contribution | Cited, otherwise a gap |
| **Pest-cycle break**: crop-family change between seasons | Cited rule, labelled "needs local review" |
| Root depth (deep-rooting crops improve infiltration) | FAO-56 Table 22 |
| Forage value | Cited, otherwise a gap |
| Market / extra income | DAM prices if cited, otherwise a gap |

**Crop list expansion** (only with cited parameters): khesari / grass pea (relay cover crop), maize (deep-rooted), sesame, mung bean (Kharif-1 legume). A crop without sources is not offered.

**Five-heading card per strategy, filled deterministically:** Why suggested · Evidence (datasets, n seasons) · Benefits · Information gaps · Risks to check locally ("confirm with your SAAO").

**Priority matching:** a matrix showing which strategy best fits which priority (extending the existing T2 property tests).

**Acceptance:**
- The baseline is always shown.
- Three or more strategies appear whenever they're feasible.
- Unsourced values appear only as gaps.
- Kc test and hindcast tests still pass.

### W5. Geospatial Mapping & Visualization (API + web)

- **Interactive map of all 64 districts** with layer switch: soil-moisture trend, heat-wave days, extreme-rain days, GRACE storage trend, NDVI stress, and frost/cold nights.
- **Year timeline slider:** 2001–2024; SMAP from 2015, GRACE from 2002.
- **Overlay compare:** two datasets side by side with a swipe control.
- **Field-level vulnerability zones on the demo fields:**
  - erosion risk (slope + bare + heavy rain);
  - water-stress hotspots (SMAP / ECOSTRESS);
  - low-lying waterlogging (NASADEM + OPERA);
  - cold-prone areas.
- **Field Passport:** each layer drawn at its real pixel size around the field, so uncertainty is visible.
- **Scenario sliders:** rain −30% to +30%, temperature +0 to +2 °C. The **backend** re-runs the water balance and heat counts (Layer 1); the web page only displays the result.

**Acceptance:**
- Every map value comes from an API response with a source.
- Slider results match the Layer 1 tests.
