## Product (new headline)
**Survey Crops: "A rotation planner that knows how *your* field floods and dries."** It helps farmers and extension officers (SAAOs) choose a year-round crop rotation for each field, using how that field actually floods and dries as seen by NASA satellites, plus its soil and the farmer's priorities. Every option is tested on 24 past seasons (2001-2024), and the plan re-adjusts the day floodwater leaves. Flood features inside it: flood-tolerant variety matching, satellite damage map vs DAE figures, (if time) safest seedbed finder. Event: NASA Space Apps, Challenge 7 "Field Shift", 13-14 Nov 2026. Dry run 12 Nov, freeze 10-11 Nov.

## Districts
Live today: Cumilla, Feni, Brahmanbaria, Noakhali, Sylhet. Planned (Tanha confirmed 24 Oct): Chattogram, Khulna, Rajshahi, Barishal (9 total, tasks T10a-d). Everywhere else: **basic mode**, NASA data only, labelled "basic, weather and soil-moisture only, not validated here" (T11).

1. `src/compute` pure deterministic Python, no AI imports, fully unit-tested. 2. `src/ml` real trained model with honest held-out metrics (empty today). 3. `src/agents` free Hugging Face model, plain state machine, max 6 steps, `guard()` as code, template fallback, never empty JSON. 4. `web/` only renders API responses.
