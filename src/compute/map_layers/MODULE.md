# map_layers (W5 map: layer catalogue, values, outlines, scenario sliders, Field Passport)
Layer: 1 compute (no AI, no network)
Code: src/compute/map_layers/layers.py, src/compute/map_layers/outlines.py, src/compute/map_layers/scenario.py, src/compute/map_layers/passport.py, src/compute/map_layers/zones.py
Purpose (2–3 sentences): Everything the map page shows, computed here and served by `src/api/map_routes.py`; the web page only renders it. Layers backed by data in the repo (NASADEM, GRACE-FO, MODIS, SMAP, W2 indicators for the five live districts) give a value per district per year; layers that are not assessed stay in the catalogue, disabled, with the reason. The scenario sliders re-run the FAO-56 water balance and the cited heat counts on past seasons with changed rain and temperature; the Field Passport shows each layer at its real pixel size for the two demo fields.
Public API (exact signatures + one-line description each):
- `catalog(status_path=STATUS_PATH)` : one entry per layer (key, label, scope, status, enabled, reason, dataset, source_url, unit, available_years, caveats); every row of the W1b status table is listed, not-assessed ones disabled with the reason.
- `layer_values(key, year=None, season=None, status_path=STATUS_PATH)` : value (or None plus a note) for all 64 districts; raises KeyError for an unknown layer and NotAssessed for a disabled one.
- `district_outlines(path=GEOJSON)` : the 64 geoBoundaries ADM2 outlines (GeoJSON) with licence, attribution and citation.
- `apply_scenario(raw, rain_pct, temp_add_c)` : copy of a weather table with rain scaled by the slider and all temperatures shifted; sliders outside -30..+30 % and 0..2 C raise ValueError.
- `heat_days_in_season(season, limits)` : days strictly above each cited limit in one season.
- `heat_limits(crop)` : the cited heat and hot-night limits of a crop (W2's thresholds).
- `default_sowing(crop)` : start of the cited sowing window as MM-DD.
- `run_on_weather(raw, latitude, elevation, crop, sowing, rain_pct, temp_add_c, kc_table, crop_params, soil, limits, years=YEARS)` : season results over 2001-2024 for one weather table (pure, no file reads).
- `run_scenario(district, crop, rain_pct, temp_add_c, sowing=None)` : baseline, what-if and the difference, with the fixed label "what-if on past seasons, not a forecast", assumptions and provenance.
- `demo_fields()` : the two demo fields with where their location comes from.
- `elevation_window(tile, lat, lon, half_width=7, data_dir=DATA_DIR)` : elevation of the 30 m pixels around a point, None for no-data.
- `slope_window(tile, lat, lon, half_width=7, data_dir=DATA_DIR)` : slope derived from that elevation (relative ranking only).
- `field_passport(field_id, half_width=7, data_dir=DATA_DIR, layers_dir=LAYERS_DIR)` : every layer in the repo as a pixel grid, and "not assessed" entries (with reason and real pixel size) for the rest.
- `lowest_third_cut(tile_elev)`, `low_lying(elev, cut_m)` : the lowest third of the whole tile's NASADEM elevations (cut, share of tile with ties) and the 1/0/NaN flag per pixel.
- `flood_days(days, status)`, `flood_cut(tile_days)`, `flood_exposed(days, cut_days)` : T3b open-water days with unknown kept unknown (0 only where observed with no event); the upper-third cut over observed pixels; exposed = at or above the cut and above 0 days.
- `overlap(a, b)`, `sample_nearest(grid, rows, cols)`, `summary(zone)`, `to_lists(zone)` : three-valued AND, nearest-pixel re-sampling, counts, JSON lists (None for unknown).
- `zones_block(field, half, data_dir, layers_dir)` : the passport's `vulnerability_zones` (low-lying, flood-exposed, overlap, plus cold-prone, erosion and water-stress as "not assessed" with reasons). Every zone is labelled "relative ranking within this tile, our choice, not a cited vulnerability class".
Inputs (data files / other modules) and their provenance: docs/w1b_data_status.csv; data/processed/{nasadem_district_static.csv, nasadem_30m_cumilla.npz, grace_district_monthly.csv, modis_district_<year>.csv.gz, smap_<district>_2015_2026.csv, indicators_districts_2001_2024.csv, district_metadata.csv, kc_table.csv}; data/reference/{bgd_adm2_districts.geojson, r13_boundary_licence.csv, crop_params.csv, crop_thresholds.csv, crop_calendar.csv}; T3b layers in data/raw/opera_layers (on this machine only, not in git; absent means "not assessed"); modules sat_layers, indicators, risk_calendar, water_balance, weather.
Outputs (shape + units + provenance fields): dicts with `provenance {dataset, source_url, resolution, units}` (values, outlines) or a `provenance` list (scenario); passport layers carry dataset, source_url, pixel_size_m, status, reason.
Reference tables used (data/reference/*.csv rows): bgd_adm2_districts.geojson metadata and r13_boundary_licence.csv (CC BY 3.0 IGO, verified 10 and 12 Nov 2026); crop_thresholds.csv heat and hot-night rows via the W2 loader; crop_params.csv FAO-56 Table 22 rows; crop_calendar.csv sowing window start.
Tests (file names + what each proves): tests/map_layers/test_scenario.py (exact rain and temperature change, slider ranges, hand-counted heat days, slider at 0/0 equals crop_season_all_years, monotone effects, label and wording), tests/map_layers/test_layers.py (every status layer listed, disabled with reason, values equal the files, gap years are None not 0, 64 outlines with licence), tests/map_layers/test_passport.py (30 m window equals the tile, no-data is None, not-in-repo layers not assessed, flood window when the T3b layers exist), tests/map_layers/test_zones.py (hand-built 4x4 grids for every zone function, cut from the whole tile not the window, unknown never 0, labels, no predict/forecast), tests/api_deploy/test_no_shapely.py (fresh interpreter with shapely, and shapely+rasterio, blocked; every route called), src/api/test_map_routes.py (envelope, provenance, error codes, endpoint equals Layer 1).
Known limitations / honest caveats: the sliders scale each day's rain and add the temperature shift; humidity, wind and sun stay as observed (stated in every response). Heat counts cover the whole crop season although each cited limit applies to one stage. NASADEM slope is relative only; GRACE-FO is regional (about 300 km, shared cells); MODIS has 2015-2024 only; the SMAP layer is the five live districts' point pixel; W2 indicator season windows are our windows. Scenario covers the five live districts and wheat, mustard, lentil, potato (the FAO-56 crops). Field-level zones: only low-lying, flood-exposed and their overlap are drawn, as relative rankings within the tile (our choice, no cited threshold); cold-prone, erosion and water-stress stay not assessed (no 30 m temperature, no cited erosion factors, no SMAP/ECOSTRESS pixel grid). Flood-exposed is one season (2024) and an upper bound; where data/raw/opera_layers is absent it says "not assessed (layer not in the repo)". The T3b flood layer needs data/raw/opera_layers (not in git). Demo field positions are the team's field record, not NASA data.
